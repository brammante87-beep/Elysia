# Gameplay

Alpha 0.1 is a visual foundation rather than a complete game loop.

## Current Playable State

When the page opens, the world appears immediately. The player can see sea at the top, a beach band below it, grass below the beach, one Hero, and two Villagers.

## Current Controls

No controls are implemented in Alpha 0.1. Input classes exist only as architecture boundaries for future work.

## Current Objective

There is no win condition or progression in Alpha 0.1. The objective is to validate that the canvas, loop, world generation, and entity rendering work correctly.
